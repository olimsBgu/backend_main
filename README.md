# Rimonim

Rimonim is a student project built for Students Think Innovation at Ben-Gurion University. We worked with the Israeli Ministry of Aliyah and Integration on a digital tool for the Hibbur Israeli program.

The idea was simple. Mentors and new immigrants create profiles, discover suitable people and choose who they would like to connect with. When the interest is mutual, they can start chatting. It is a Tinder-like matching flow designed for mentorship rather than dating.

This repository contains the backend of the project. It was built as part of our team's work on the product.

## What we built

- Email verification and passwordless login codes
- Profiles for mentors and mentees
- Matching based on interests, university, field of study and city
- Like, skip and saved-profile actions
- Mutual matches between users
- Real-time chat over WebSockets
- Image uploads and profile editing
- An admin panel for managing users, matches and chats
- API documentation generated by Django Ninja at `/docs`

## Tech stack

- Python 3.11
- Django 5
- Django Ninja
- Django Channels and Daphne
- PostgreSQL
- JWT authentication
- Docker and Docker Compose
- Pytest
- Nginx configuration for deployment

## Running locally

Create a `.env` file in the project root.

```env
DJANGO_SECRET_KEY=replace-me
DEBUG=1
ALLOWED_HOSTS=localhost,127.0.0.1
POSTGRES_DB=rimonim_db
POSTGRES_USER=rimonim_user
POSTGRES_PASSWORD=securepassword
DB_HOST=db
DB_PORT=5432
ENV=dev
```

Start the backend and database.

```bash
docker compose up --build
```

The API will be available at `http://localhost:8000` and the interactive documentation at `http://localhost:8000/docs`.

## Tests

```bash
pytest
```

## Project background

Rimonim was developed as a working prototype and presented to representatives of the Ministry of Aliyah and Integration. Although it did not win the final competition, it gave us the chance to take a real social problem from research and interviews to a functioning product.

The project is now public as part of our portfolios and as a record of the work we did together.
