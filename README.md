# Rimonim

Rimonim is a mentorship matching platform for new immigrants entering Israeli academic life. It was developed by a team of immigrant students during **Students Think Innovation at Ben-Gurion University**, in collaboration with the **Israeli Ministry of Aliyah and Integration**, for the **Hibbur Israeli** program.

[View the product presentation](https://www.canva.com/design/DAGkztSxyus/DBOGgR_Ij7MKyM6qyGfaow/view?utlId=hefd60f07c4)

## The problem

Starting university in a new country is not only an academic challenge. New immigrants must also build a social network, understand an unfamiliar system and find people who can help them navigate it.

Hibbur Israeli addresses this through mentorship, but the original process had several limitations:

- mentors and mentees were assigned with limited control over compatibility;
- registration and coordination required too much manual work;
- arranging and tracking meetings was difficult;
- program administrators had limited visibility into participation and outcomes.

A poor match could make conversations feel forced and cause participants to disengage. The team behind Rimonim experienced these challenges firsthand and designed the product around a simple idea: mentorship works better when both people actively choose the connection.

## The solution

Rimonim turns mentorship assignment into a structured, mutual matching flow.

Mentors and mentees create profiles containing their university, field of study, city and interests. Users discover relevant people, express interest or skip a profile, and become matched when the interest is mutual. From there they can communicate through real-time chat and continue the mentoring relationship inside the platform.

The prototype supports:

- email verification and passwordless login codes;
- mentor and mentee profiles;
- discovery based on interests, university, field of study and city;
- like, skip and saved-profile actions;
- mutual matching;
- real-time chat over WebSockets;
- image uploads and profile editing;
- administration of users, matches and chats;
- activity data that can support future reporting and program evaluation.

AI-assisted ranking was part of the product roadmap. The current prototype uses structured profile signals rather than claiming a production ML recommendation system.

## How it works

1. A participant registers and verifies their email.
2. They complete a profile with their role, location, education and interests.
3. The platform presents potentially relevant mentors or mentees.
4. Each participant independently chooses whether to connect.
5. Mutual interest creates a match and opens a real-time conversation.
6. Administrators can oversee users, matches and chats from the management interface.

## Who it serves

- **New immigrant students** looking for guidance, community and practical support.
- **Mentors** who want to help someone with compatible interests or experience.
- **Program administrators** who need a scalable way to manage participation and understand activity.

The same model can be adapted to other educational, social, public-sector or workplace mentoring programs.

## Repository scope

This repository contains the backend of the working prototype. It exposes the API, manages authentication and profile data, implements matching actions and mutual matches, powers WebSocket chat, and provides administrative capabilities.

Interactive API documentation is generated by Django Ninja at `/docs`.

## Tech stack

- Python 3.11
- Django 5
- Django Ninja
- Django Channels and Daphne
- PostgreSQL
- JWT authentication
- Docker and Docker Compose
- Pytest
- Nginx configuration for deployment

## Running locally

Create a `.env` file in the project root.

```env
DJANGO_SECRET_KEY=replace-me
DEBUG=1
ALLOWED_HOSTS=localhost,127.0.0.1
POSTGRES_DB=rimonim_db
POSTGRES_USER=rimonim_user
POSTGRES_PASSWORD=securepassword
DB_HOST=db
DB_PORT=5432
ENV=dev
```

Start the backend and database.

```bash
docker compose up --build
```

The API will be available at `http://localhost:8000` and the interactive documentation at `http://localhost:8000/docs`.

## Tests

```bash
pytest
```

## Project background

Rimonim was developed from research, interviews and the team's own experience adapting to university life after immigrating to Israel. The team presented the working prototype to representatives of the Ministry of Aliyah and Integration.

The project is public as a portfolio case study and as a record of the team's work on a real social problem.
